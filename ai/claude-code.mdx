[Claude Code](https://code.claude.com/docs) is Anthropic's CLI tool for working with Claude directly in your terminal. You can connect it to TryPost's MCP server to manage your social media scheduling with natural language.

## Prerequisites

- Claude Code installed ([install guide](https://code.claude.com/docs/en/setup))
- A TryPost Cloud account with an active subscription ([plans and billing](/knowledge-base/settings/plans-and-billing))

## Setup

<Steps>
  <Step title="Add the TryPost MCP server">
    Run the following command in your terminal:

    ```bash
    claude mcp add --transport http trypost https://app.trypost.it/mcp/trypost
    ```

    This adds the server for the current project, for you only (local scope). Use `--scope project` to share it through `.mcp.json`, or `--scope user` for every project.
  </Step>
  <Step title="Sign in through your browser">
    Start Claude Code and trigger the first TryPost call:

    ```bash
    claude
    ```

    ```
    List all my scheduled posts
    ```

    Claude Code opens a browser window asking you to sign in to TryPost and authorize the connection. Sign in, pick the **Workspace** this connection may use and click **Authorize**. Claude Code stores the OAuth token and refreshes it automatically from then on. To use another workspace, connect again and pick it.
  </Step>
</Steps>

## Manual configuration

If you prefer to edit the config file directly, this is what `claude mcp add --scope project` writes to `.mcp.json` (no `Authorization` header — OAuth is discovered from the URL):

```json
{
  "mcpServers": {
    "trypost": {
      "type": "http",
      "url": "https://app.trypost.it/mcp/trypost"
    }
  }
}
```

Drop it in `.mcp.json` for project scope. With `--scope user` the same block goes under `mcpServers` in `~/.claude.json`.
