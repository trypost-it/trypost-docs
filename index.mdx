# TryPost Documentation

TryPost is an open-source social media scheduler. Plan ideas, write one post for every network, queue it on each channel's posting times, and see how it did in Insights — on LinkedIn, X, Facebook, Instagram, TikTok, YouTube, Threads, Pinterest, Bluesky, Mastodon, Telegram, Discord and Google Business Profile.
