A template is a reusable post text. **Create › Templates** keeps TryPost's library next to the templates your team and you write. Using a template puts its text in the composer; from there it is a normal post you can change freely.

Every member of the workspace can use and create templates.

## Scopes

| Tab | What it holds |
| --- | --- |
| **Discover** | TryPost's library, marked **By TryPost**. Read-only. |
| **Team** | Templates visible to everyone in this workspace. Anyone in the workspace can edit them. |
| **Personal** | Templates only you can see. |

**Discover** has a search box and four filters:

- **Type**: Tip, Case study, Story, How-to, Question, Opinion, List, Behind the scenes
- **Made for**: Business, Individual
- **Format**: Single text, Threaded
- **Goal**: Engagement, Connection, Reflection, Expertise, Promotion, Education, Celebration

## Use a template

<Steps>
  <Step title="Open it">
    Click a template card to see its full text.
  </Step>
  <Step title="Use or copy">
    **Use template** opens the [composer](/knowledge-base/publish/composer) with the template's text. **Copy template** copies the text to your clipboard.
  </Step>
</Steps>

Inside the composer, the **Templates** button opens the same three tabs in a side panel. Picking a template there inserts its text into the post you are writing.

## Create a template

Click **New template** and fill in:

- an emoji
- **Title**
- **Description**: "A line for your future self about when to use this template."
- **Body**: the text that goes into the composer
- **Visibility**: **Only me** (Personal) or **My team** (Team)

Click **Create template**. Only the creator can change a template's visibility.

## Duplicate, edit and delete

From a template's menu:

- **Duplicate** makes a copy and asks where to save it: **Only me** or **My team**. This is how you start from a library template and adapt it.
- **Edit** and **Delete** appear on templates you can edit: every Team template, and your own Personal ones.

Deleting a template does not change posts already created from it.

<Note>
  Templates are web only. There is no API endpoint or MCP tool for them.
</Note>
