Labels are colored tags for posts and ideas: a campaign, a content pillar, a client. Labels belong to the workspace, so every member sees and uses the same list.

Every member of the workspace can create, edit and delete labels. Find them in **Settings → Labels**.

## Create a label

Click **New Label**, enter a **Name**, pick a **Color**, then **Create Label**.

The list shows how many posts use each label. **View posts** opens Publish filtered by that label.

## Add labels

- **Posts** — in the [composer](/knowledge-base/publish/composer), or from a post card's menu with **Edit labels** on the Publish page. A post can have several labels.
- **Ideas** — in the idea editor. See [Ideas](/knowledge-base/create/ideas).

## Filter by label

- **Publish** — the **Labels** filter shows only posts with the labels you pick. **Untagged** shows posts without any label, and **Manage labels** opens this settings page. See [Publish](/knowledge-base/publish/overview).
- **Channel insights** — filter a channel's per-post performance by label to compare campaigns. See [Channel insights](/knowledge-base/insights/channel-insights).
- **Ideas** — filter the board or gallery by label.

## Edit or delete

Use **Edit label** to change the name or color; posts and ideas show the change right away. **Delete label** removes it from every post and idea, after a confirmation. The posts and ideas themselves stay.

## Via the API and MCP

| Task | REST | MCP |
|------|------|-----|
| List | [List labels](/api-reference/labels/list-labels) | `list-labels-tool` |
| Create | [Create label](/api-reference/labels/create-label) | `create-label-tool` |
| Update | [Update label](/api-reference/labels/update-label) | `update-label-tool` |
| Delete | [Delete label](/api-reference/labels/delete-label) | `delete-label-tool` |

Over the API a color is a hex code in `#RRGGBB` format. To label a post, send `label_ids` when you [create](/api-reference/posts/create-post) or [update](/api-reference/posts/update-post) it.
