# Server Requirements

This guide covers the requirements for self-hosting TryPost.

## Minimum Requirements

| Component | Minimum | Recommended |
|-----------|---------|-------------|
| CPU | 1 core | 2+ cores |
| RAM | 1 GB | 2+ GB |
| Storage | 10 GB | 20+ GB (depends on media storage) |

## Software Requirements

### Required

- **PHP 8.4+** (the Docker image ships 8.4) with extensions:
  - BCMath, Ctype, JSON, Mbstring, OpenSSL, PDO, Tokenizer, XML
  - **pdo_pgsql** or **pdo_mysql**, matching the database you chose — without it the app fails at boot with *could not find driver*
  - **pcntl** (required by Horizon)
  - **intl**, **zip**, **exif**, **sockets**
  - **GD** and **Imagick** (both ship in the Docker image). HEIC/HEIF uploads are converted to JPEG only when Imagick is built with HEIC support; without it they are rejected with a clear message and every other format still works
  - Redis extension (or use Predis via Composer — the Redis **service** is still required)
- **Composer** 2.x
- **Node.js** 20.19+ or 22.12+ and npm (required by Vite 8) — not needed if you only run the published Docker image
- **PostgreSQL** or **MySQL** — both are fully supported (MySQL from TryPost 2.0); see [choosing a database](/self-hosting/configuration#database)
- **Redis** — queues, cache and locks (the Compose files ship Redis 7)

### Long-running processes

TryPost needs three processes besides the web server. The [Docker image](/self-hosting/docker) starts them for you; on bare metal see [Production setup](/self-hosting/production).

- **Horizon** — the queue workers that publish posts, send email and webhooks, and collect analytics
- **Reverb** — WebSockets for live updates in the app
- **Scheduler** — `php artisan schedule:run` every minute (or `schedule:work`)

### Optional

- **Nginx** or **Apache** (for production bare-metal)
- **Supervisor** (for Horizon, Reverb, and related workers)
- **SSL certificate** (Let's Encrypt recommended)

## PHP Configuration

Recommended `php.ini` settings:

```ini
upload_max_filesize = 1G
post_max_size = 1G
memory_limit = 512M
max_execution_time = 600
```

Match these to your reverse-proxy body-size limit (`client_max_body_size` in Nginx, etc.). The published Docker image uses the same 1G upload cap with a lower `memory_limit = 256M` and `max_execution_time = 60`; the higher values above give large video uploads and image processing more headroom on bare metal.

## Supported Operating Systems

TryPost can run on any OS that supports the required software:

- Ubuntu 22.04+ (recommended)
- Debian 11+
- CentOS/RHEL 8+
- macOS (for development)
- Windows with WSL2 (for development)

## Storage Considerations

Media files (images, videos, documents) can be stored:

- **Locally** — `FILESYSTEM_DISK=public` + `php artisan storage:link`
- **S3** — Amazon S3
- **R2** — Cloudflare R2
- **Spaces** — DigitalOcean Spaces
- **Any S3-compatible** — MinIO, etc.

For production with heavy media usage, object storage is recommended. See [Configuration → File Storage](/self-hosting/configuration#file-storage).
